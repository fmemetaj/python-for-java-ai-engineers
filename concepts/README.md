# Concepts

Concept-by-concept lessons for Modules 0A, 0B, 1, 2, 3, 4, 5, 6, and 7. Start at [modules/0a-fundamentals/README.md](../modules/0a-fundamentals/README.md) and follow the module READMEs through [Module 7](../modules/7-capstone/README.md).

Grade a single concept (your files in `exercises/`):

```bash
uv run pytest concepts/0_11
```

`COURSE_IMPL=solutions` grades the committed answers. Leave that to CI unless you are checking a solution after you have tried the exercise.
