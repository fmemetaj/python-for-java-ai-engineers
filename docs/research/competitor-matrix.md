## Positioning gap (synthesis)
No resource found combines all of: (a) an explicit Java → Python bridge, (b) a plain-SDK-first approach that is vendor-neutral where possible, (c) evals, observability, and cost from module 1, (d) a CI-verified, mock-runnable codebase, and (e) free access with disclosed costs. Hysen Labs is the closest on (b)–(e). Microsoft is the closest on free and maintained.

Not covered (honest gaps): the x namespace was not searched; Stack Overflow was not analyzed directly; reviews of FSDL, Microsoft agents, and Hugging Face were not collected.
