# Guides: when something feels unfamiliar

The **seven core notebooks are the whole required path**. These guides are *optional, targeted references*, not extra lessons. README times are estimates; install and this optional reading are outside those estimates.

| Guide | Read when... |
| --- | --- |
| [01 — Cursor, VS Code or Jupyter](01_editor_setup.md) | You cannot select the correct Python interpreter or notebook kernel |
| [02 — Python for Java engineers](02_java_python_map.md) | You understand Java code but a Python language feature surprises you |
| [03 — Async and generators](03_async_and_streaming.md) | You are unsure when `await` runs concurrently or why `yield` matters |
| [04 — Pydantic and decorators](04_pydantic_and_decorators.md) | You confuse validation, type hints, decorators or agent tool schemas |
| [05 — uv and troubleshooting](05_uv_and_debugging.md) | Imports, dependencies, kernels or tests fail |
| [07 — Extra Python foundations](07_extra_python_foundations.md) | You need imports, f-strings, JSON, pickle safety or a Docker primer | 
| [06 — Optional local AI lab](06_local_ai_lab.md) | You want the Gradio/Ollama visual capstone after the core |

**Suggested approach:** finish one notebook, consult the matching guide only for a concrete blocker, then return to the notebook. None of these guides requires purchasing a course or calling a paid API.
